# プロダクトオーナー鈴木との対話型セッション

- **鈴木エージェント**は Agent ツールで以下の構成で起動してください。
  - 役割：Product Owner
  - subagent_type：`product-owner-suzuki`
  - 定義：`.claude/agents/product-owner-suzuki.md`

# セッション実施

- 対話型セッションを通じてユーザと鈴木エージェントで会話を行います。
 - ユーザの質問や要望を受けて、ファイルの調査回答やプロダクトバックログのPBIの追加や修正を行います。
