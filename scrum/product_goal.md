# プロダクトゴール

## プロダクト名
**社内タスク管理Webアプリ（TaskLite）**

## プロダクトビジョン

社内メンバーが日々のタスクを迷わず登録・共有し、「誰が・何を・いつまでに」を一目で把握できる状態をつくる。散在するタスク管理を一元化し、進捗の見える化によってチームの抜け漏れをなくすことを目指す。まずはローカルで動く最小構成から始め、将来的には社内サーバへのデプロイによる本格運用へ育てていく。

## プロダクトゴール

> プロダクトゴールはプロダクトバックログに含まれ、残りのプロダクトバックログはプロダクトゴールを実現する「何を」を定義するために出現する。
> — スクラムガイド 2020

### 現在のプロダクトゴール

**「社内チームがタスクの登録・状態管理・期限管理・担当者での絞り込みをローカルで完結でき、進捗を一覧で把握できる状態を実現する」**

#### ゴール達成の条件
1. タスクを登録・一覧表示でき、状態（未着手 / 対応中 / 完了）を変更できる
2. タスクに期限（日付）を設定でき、期限順に並べ替えて表示できる
3. 担当者でタスクを絞り込んで表示できる
4. ローカル環境（SvelteKit SPA + Node.js API + SQLite）で一連の操作が動作する

## ステークホルダー
| 名前 | 役割 | 関心事項 |
|------|------|----------|
| 社内チームメンバー | エンドユーザー | タスクの登録・状態更新が簡単にできること |
| チームリーダー | 業務管理者 | 担当者別・期限別に進捗を把握できること |
| 佐藤 | 顧客・利用部門代表 | 依頼要件（order001）が満たされること |

## 成功指標
- タスクの登録から状態変更・完了までを画面上で完結できる
- 期限順の並べ替え・担当者フィルタが期待通りに機能する
- ローカル環境で追加セットアップなく起動・操作できる
